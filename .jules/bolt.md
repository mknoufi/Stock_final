## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** When creating or modifying generic wrapper components around lists like `VirtualList` that implement `React.forwardRef`, using a simple `forwardRef` will drop generic typing on props, and using a cast on the export requires `eslint-disable-next-line react/display-name` to pass linting. Also, passing a `ref` down to a component masking FlashList necessitates the `ref` typed as `any` because `FlashList` from `@shopify/flash-list` is exported as a value, not a generic type.
**Action:** Ensure `React.forwardRef` wrappers around generic React Native list components cast their exports to retain generics (e.g., `as <T>(props: Props<T> & { ref?: React.Ref<any> }) => React.ReactElement;`). Disable `react/display-name` linting if necessary, and use `any` when typing refs for `FlashList` instances to bypass `TS2749`.
