## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** Calling `fetchall()` on a pyodbc cursor unnecessarily loads the entire result set into a Python list, spiking memory usage for large query responses.
**Action:** When querying SQL databases via pyodbc, prefer iterating over the cursor object directly in a loop or comprehension (e.g., `[row for row in cursor]`). When writing unit tests for this pattern, the cursor mock must implement `__iter__` to return an iterator (e.g., `mock_cursor.__iter__.return_value = iter(MOCK_DATA)`).
