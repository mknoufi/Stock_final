## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** The Python backend previously contained numerous N+1 query bottlenecks where multiple database lookups were performed iteratively within loops using `find_one()`. This is particularly inefficient for database operations, especially over the network.
**Action:** Always replace iterative `find_one()` queries inside loops with a single bulk query using the MongoDB `$in` operator. Map the resulting documents into an in-memory dictionary using an appropriate ID key for O(1) retrieval inside the loop. This maintains the original order and handles duplicate IDs efficiently while drastically reducing database roundtrips.
