## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** When refactoring N+1 queries in batch processing loops (e.g., replacing `find_one()` with a pre-fetched `$in` query and an in-memory set), always update the in-memory set during the loop iteration (e.g., `processed_ids.add(record.id)`). **Action:** Always insert newly processed record IDs into the in-memory tracking set immediately after database insertion inside the loop.
