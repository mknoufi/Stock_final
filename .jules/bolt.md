**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** Replacing React Native's standard `FlatList` with `VirtualList` (powered by Shopify's FlashList) is an extremely straightforward and highly effective performance optimization for rendering long lists in the React Native codebase. It drastically reduces rendering overhead and prevents frame drops during scrolling. A critical detail is that `VirtualList` requires an accurate `estimatedItemSize` prop to function optimally. This value should be calculated by inspecting the component's styling (e.g., margins, paddings, and expected content height) rather than guessing.

**Action:** Whenever reviewing components that render long lists (like notifications, activity logs, user lists, etc.), check if `FlatList` is being used without a wrapping `ScrollView`. If so, it is a prime candidate for migration to `VirtualList`. Ensure the correct `estimatedItemSize` is computed and passed to maximize the performance benefits.
