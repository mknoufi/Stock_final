## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** When creating generic wrapper components for lists like FlashList (VirtualList) in React Native that use `React.forwardRef`, using standard arrow functions with a single generic like `<T>` causes parsing issues as JSX or typescript limits.
**Action:** Always cast the final forwardRef export explicitly (e.g. `export const VirtualList = React.forwardRef(VirtualListBase) as <T>(props: VirtualListProps<T> & { ref?: React.Ref<any> }) => React.ReactElement;`) instead of declaring it at the start, and type the base implementation as `<T extends any>`.
