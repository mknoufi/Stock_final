## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** When resolving N+1 `find_one` loops with a bulk `$in` query, the database driver does not guarantee that the returned items match the order of the input IDs, nor does it yield duplicates if the input IDs contained them. If the original loop appended results to a list sequentially, the bulk replacement must map the database results to an intermediate dictionary, and then iterate over the *original* input ID array to construct the final list.
**Action:** Always map bulk `$in` results to a dictionary and reconstruct the output using a list comprehension over the input array to preserve ordering and duplicate behavior.
