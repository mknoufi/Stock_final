## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** When adding explanatory comments (like `⚡ Bolt: ...`) inside JSX, specifically as the first child within the return branch of a ternary operator (`condition ? ( ... ) : ( {/* comment */} <Component /> )`), React's JSX parser will throw a `Parsing error: ')' expected`. This is because the ternary expects a single expression, and a JSX comment plus a component resolves to multiple items without a parent.
**Action:** When adding comments near JSX elements returned by ternaries, either wrap the comment and the component in a React Fragment (`<> {/* comment */} <Component /> </>`) or place the comment inside the component's opening tag or directly before the ternary if applicable.
